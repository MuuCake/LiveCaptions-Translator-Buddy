## Features

- **Live Captions** — Capture System Audio or Microphone input using Windows 11 Live Captions.
- **Real-Time Translation** — Choose Google Translate or Tencent TranSmart, with incremental translation updates.
- **Bilingual Preview & Export** — Display and save original, translated, or bilingual subtitles.
- **TXT Recording** — Custom filenames, save locations, optional timestamps, and pause/resume support.
- **History & Recovery** — Automatic backups, SQLite history, search, and a built-in TXT reader.
- **Desktop Pet** — Interactive Wakaba Mutsumi with animations, dragging, resizing, and customizable subtitle bubbles.
- **Customizable UI** — 12 interface languages and Windows light/dark theme support.

## Quick Start

1. Download the latest ZIP from [GitHub Releases](https://github.com/MuuCake/LiveCaptions-Translator-Buddy/releases/latest).
2. Extract the complete ZIP, including the `_internal` folder.
3. Run `LiveCaptionV1.5.0.exe`.
4. Select **System Audio** or **Microphone**.
5. Configure translation and TXT recording settings as needed.
6. Start recording and save your transcripts.

## Translation Notes

**For users in mainland China:** Tencent TranSmart is recommended, as Google Translate may not be accessible on some networks.

**繁體中文提醒：** 中國大陸用戶建議優先選擇「騰訊翻譯（Tencent TranSmart）」。Google 翻譯在部分網路環境下可能無法正常使用。

Online translation requires an internet connection. Results and response times depend on the selected service.

---

## Requirements & Notes

- **OS:** Windows 11 (64-bit), with Windows Live Captions available.
- **Python:** Not required when using the packaged application.
- **Languages:** 12 UI languages are supported. Speech recognition languages depend on Windows Live Captions.
- **Security:** The application is not currently code-signed, so Windows may display a security warning.
